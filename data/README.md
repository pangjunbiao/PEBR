# Project data

See [DATASETS.md](../DATASETS.md) for source information, local paths, and
expected SHA-256 checksums.

## Access

The Quick Replay input archive contains raw CSVs and derived records. Use an
approved copy obtained through the project maintainers. Contact the authors
listed in the manuscript for dataset access and redistribution terms. The
[Quick Replay release](https://github.com/pangjunbiao/PEBR/releases/tag/quick-replay-v1)
provides the scripts and instructions for readers who have the approved inputs.

## Local layout

- `data/raw/` contains the source CSVs.
- `data/processed/` contains datasets generated by full data preparation.
- `data/manifests/` contains preparation records, folds, samples, and queries.
- `data/annotations/` contains category labels exported during Indian transport
  data preparation.

Quick Replay restores the saved inputs to their original paths and uses the
archived processed datasets under
`outputs/revision_study/step2/.../data/processed/`.
The [synthetic tests](../README.md#try-the-code-with-synthetic-data) can run
with just the code and documented Python dependencies.

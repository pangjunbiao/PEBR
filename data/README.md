# Project data

Download `PEBR_Quick_Inputs.zip` and `PEBR_Quick_Replay_Kit.zip` from the
[PEBR Quick Replay v1 release](https://github.com/pangjunbiao/PEBR/releases/tag/quick-replay-v1).
Follow `REPRODUCE_QUICK.md` inside the replay kit to restore the saved
inputs into your local project.

- `data/raw/` contains the source CSVs.
- `data/processed/` contains datasets generated by full data preparation.
- `data/manifests/` contains records of sources, folds, samples, and queries.
- `data/annotations/` contains category labels exported during Indian transport data preparation.

Quick Replay uses archived processed datasets under
`outputs/revision_study/step2/.../data/processed/`.
